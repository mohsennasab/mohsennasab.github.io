Fundamentals of Python for H&H Modeling and Analysis

A practical Python course for water resources engineers who want usable scripting skills for hydrologic and hydraulic modeling without turning into software engineers. Learn with real USGS streamflow, spatial vector and raster layers, Atlas 14 design storms, soils, NLCD, NAIP imagery, and snowpack grids directly in Google Colab.

What Makes This Course Different

          
Designed for practicing engineers who already understand runoff, gauges, and watersheds and want clear code that fits daily engineering work.

        

        

          

            
Real-World Focus

            
Every lesson works through daily H&H tasks (time series, vector watersheds, DEMs, USGS stream gauges, precipitation frequency storms, soils, land cover, imagery, and snowpack volume) with real public datasets.

          

          

            
Clarity Over Complexity

            
The emphasis stays on readable, commented code that replaces repetitive spreadsheet steps, documents engineering assumptions, and creates reproducible tables and figures.

          

          

            
AI-Assisted Learning

            
AI assistants have changed how engineers write and debug scripts. Each module includes practical prompts that help you inspect unfamiliar libraries, spot unit or projection mistakes, and adapt code with engineering judgment.

A Note on Units

            
Many examples use U.S. customary units alongside SI units (such as cfs alongside cms, or inches alongside millimeters) to match USGS and NOAA agency conventions. Practice converting between systems as you work through the notebooks.

            How This Course Was Reviewed and How You Can Report Issues
            

              
This course has been assembled and reviewed manually with AI-assisted coding tools helping check explanations, formatting consistency, and edge cases. Every lesson is reviewed by the author before publication.

              
Because Python geospatial libraries update over time, a cell that runs cleanly today may need an adjustment later. If you encounter an issue or outdated server URL, please open an issue on GitHub.

            

          


          

            Contributing a New Module or Lesson
            

              
Submission Steps

              
    
                
  1. Open a GitHub issue proposing your topic before writing full code.
    2. 
                
  2. Fork mohsennasab/python-fundamentals-hh and build your lesson on a feature branch.
    3. 
                
  3. Include Lesson Level, Purpose, Learning Objectives, Prerequisites, and 2 to 3 practical AI prompts at the top of the notebook.
    4. 
                
  4. Verify the notebook runs cleanly end-to-end in a fresh Google Colab session and submit a pull request.
    5. 
              

              
Content Standards

              
    
                
  • Ground examples in real H&H engineering tasks (flood mapping, frequency curves, hydrographs, soils, snow).
    • 
                
  • Write clear, readable Python with helpful comments where beginners could get stuck.
    • 
                
  • Include only public or anonymized sample datasets placed inside a module data/ folder.
    • 
              

            

          


          

            Data Sharing Guidelines for Public Repositories
            

              
Every dataset committed to the course repository must be safe for open educational distribution.

              
Acceptable Sources

              
    
                
  • Public agency datasets (USGS, NOAA, USDA/NRCS, NSIDC, state DNRs, EPA).
    • 
                
  • Synthetic or randomized teaching datasets and anonymized watershed excerpts.
    • 
              

              
Before Committing New Data

              
    
                
  1. Confirm no client, employer, or proprietary project files are traceable inside code, attributes, or metadata tags.
    2. 
                
  2. Verify that no credentials, API keys, tokens, or internal server paths remain printed inside notebook outputs.
    3. 
                
  3. Verify clearance for public educational release before pushing.
    4.
